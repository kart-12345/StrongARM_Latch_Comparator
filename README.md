# StrongARM_Latch_Comparator
Implementation of StrongARM_Latch_Comparator in cadence.

## Project Overview

This project focuses on the transistor-level design, simulation, and physical layout implementation of a **StrongARM Latch Comparator** using Cadence Virtuoso with a 180nm CMOS technology process.

The StrongARM latch is a high-speed dynamic comparator widely used in analog and mixed-signal circuits, particularly in Analog-to-Digital Converters (ADCs). It operates using differential input sensing and positive feedback regeneration to achieve fast and reliable decision-making with low static power consumption.

## Project Objectives

- Design a StrongARM latch comparator using CMOS transistors.
- Understand the precharge, evaluation, and regenerative amplification phases.
- Study differential input response and output switching characteristics.
- Perform transient simulations to verify circuit functionality.
- Analyze important comparator performance parameters.
- Implement the physical layout of the comparator.
- Perform Design Rule Check (DRC) and Layout Versus Schematic (LVS) verification.

## Tools and Technology

- **EDA Tool:** Cadence Virtuoso
- **Technology Node:** 180nm CMOS
- **Design Methodology:** Full-Custom Transistor-Level Design
- **Circuit Type:** Dynamic Latch-Based Comparator
- **Simulation:** Transient Analysis
- **Physical Design:** Custom Layout Implementation

## Design and Implementation Flow

1. Study the StrongARM latch comparator architecture and working principle.
2. Develop the transistor-level schematic using Cadence Virtuoso.
3. Configure the 180nm CMOS technology library.
4. Perform transient simulations to analyze comparator operation.
5. Examine output regeneration and switching characteristics.
6. Implement the corresponding physical layout.
7. Carry out DRC and LVS verification.
